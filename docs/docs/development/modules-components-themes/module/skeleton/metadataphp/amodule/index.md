# List of all $aModule keys

This is a list of all keys that are possible in the file `metadata.php` in the array `$aModule` in any metadata version:

- [id](./id.md) - Unique module identifier
- [title](./title.md) - Module title with language support
- [description](./description.md) - Module description with language support
- [thumbnail](./thumbnail.md) - Module thumbnail image
- [version](./version.md) - Module version number
- [author](./author.md) - Module author/developer
- [url](./url.md) - Module vendor website URL
- [email](./email.md) - Module vendor email address
- [extend](./extend.md) - Shop class extensions
- [controllers](./controllers.md) - Module controller definitions
- [templates](./templates.md) - Smarty template registration
- [blocks](./blocks.md) - Smarty template block extensions
- [settings](./settings.md) - Module configuration settings
- [events](./events.md) - Module activation/deactivation events
- [lang](./lang.md) - Default module language
- [smartyPluginDirectories](./smarty-plugin-directories.md) - Smarty plugin directories
