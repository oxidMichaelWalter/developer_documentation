# Development

This section contains development-related resources for OXID eShop.

## Modules, Components & Themes

Project wide development options, modules, themes and components are the containers with which you can customize, extend or configure the OXID eShop:

- **[Module Development](modules-components-themes/module/)**: Create custom modules to extend shop functionality
- **[Theme Development](modules-components-themes/theme/)**: Design and implement custom shop themes
- **[Project Configuration](modules-components-themes/project/)**: Configure modules and themes for your project
- **[Component Development](modules-components-themes/component)**: Build reusable components
- **[Quality Assurance](modules-components-themes/quality)**: Best practices for code quality

## Testing

This section contains everything related to testing:

- **[Integration Testing](testing/integration)**: Test component interactions

- **[Codeception Framework](testing/codeception/)**: Complete testing framework for OXID eShop

## Development Workflow

1. **Setup**: Start with [Getting Started](/docs/getting-started/) to set up your environment
2. **Architecture**: Understand the [System Architecture](/docs/system-architecture/) 
3. **Module Development**: Create your first [Module](modules-components-themes/module/tutorials/create-basic-module)
4. **Testing**: Implement [Tests](testing/) for your code
5. **Deployment**: Prepare for [Updates](/docs/update/) and production
