# Acceptance tests with Codeception

OXID eShop supports [Codeception acceptance tests](https://codeception.com/) which this is the recommended way to
write (module) acceptance tests based on OXID's [flow](https://github.com/OXID-eSales/flow_theme/)
or [wave](https://github.com/OXID-eSales/wave_theme/) theme.
