# Installation

This section guides you through the complete installation process of OXID eShop for development purposes.

## Installation Steps

Follow these steps in order to set up OXID eShop for development:

1. **[Environment Preparation](environment-preparation)**: Check system requirements and prepare your development environment
2. **[eShop Installation](eshop-installation)**: Install OXID eShop using Composer
3. **[Troubleshooting](troubleshooting)**: Solutions for common installation issues

## Alternative Installation Methods

For special cases where the standard installation isn't possible:

- **[Installation without Composer](eshop-installation-without-composer)**: Alternative deployment methods

## Quick Start

For experienced developers who want to get started quickly:

1. Check [system requirements](environment-preparation#system-requirements)
2. Run the [Composer installation](eshop-installation#composer-installation)
3. Configure your web server and database
4. Run the setup wizard in your browser
